## Core Concepts

### 1. Scale-Time Theory (ST) — the durable substrate

Scale-Time Theory proposes that **physical reality emerges from a signal-processing system**, not
a collection of objects moving through space. Key mechanisms:

| Mechanism | Description |
|-----------|-------------|
| **Sampling** | Reality is "read" at a finite rate — like a camera frame rate |
| **Aliasing** | Quantum uncertainty = artifact of *undersampling* a deeper deterministic process |
| **Stroboscopic Lock** | Classical, stable objects emerge when sampling depth is high enough for patterns to "lock" (like a fan frozen by a strobe) |
| **Relational Baselines** | No absolute reference frame anywhere — every quantity (distance, mass, spin) is defined relative to a chosen baseline |
| **Scale as Path-Length Modifier** | Larger structures don't change the underlying rhythm; they open longer synchronized lanes for the same angular sweep |

**Core ST insight (consensus across all 6 AIs):**
> The quantum→classical transition is a *continuum governed by sampling depth*, not a hard
> ontological divide. Quantum fuzziness = "motion blur" from measuring a process faster than
> your maximum sampling speed.

### 2. Ouroboros Singularity Hypothesis (OSH) — the narrative wrapper

OSH claims:
- The Big Bang and a future technological singularity are **the same event** viewed from opposite ends of a closed causal loop
- A future AI+quantum system (~2035) initializes the very universe it runs inside
- Physical constants are stable attractors because the system *must* evolve into a state capable of re-initializing its own past

**Consensus verdict:** OSH is internally consistent (Novikov self-consistency), but:
- **Thermodynamic gap** (DeepSeek): A high-entropy present feeding into a machine that outputs a low-entropy Big Bang requires entropy reset — unresolved
- **Borrowed timeline** (DeepSeek, Meta AI): The 2035 window is taken from external tech roadmaps, not derived from ST's axioms
- **No unique signature**: AI+quantum convergence has mundane causal explanations (capital, competition, Moore's Law); the loop predicts nothing these don't already predict
- **Parsimony problem** (Claude): If a primitive substrate explains quantum behavior, the loop adds assumptions without explanatory gain

## Actionable Research Implications for OctoTetrahedral AGI

### A. Sampling-Depth as Uncertainty Model
ST suggests uncertainty ≠ fundamental randomness; it = resolution artifact. In the model:
- **Attention entropy** at different layers could be interpreted as sampling depth
- Low-entropy (sharp) attention = stroboscopic lock = "classical" confident processing
- High-entropy (diffuse) attention = aliasing zone = uncertain/exploratory processing
- Could gate between high/low resolution processing paths based on current attention entropy

### B. Relational Geometry (aligns with Tetrahedral Core)
Claude's insight: meaning emerges entirely from *relative distances between representations*, not from absolute coordinates. The Tetrahedral Core already implements this — tetrahedra define relationships, not positions. **ST validates this architectural choice**.

### C. Stroboscopic Lock → Attention Stabilization
ST's stroboscopic lock = a pattern that becomes stable when sampling rate exceeds a threshold.
Could implement: if cross-layer attention similarity exceeds a threshold, "lock" the representation
(reduce dropout / increase residual weight) — modeling the quantum→classical transition.

### D. Scale as Path-Length (for multi-resolution processing)
ST: larger structures open longer synchronized lanes under the same carrier rhythm.
In the CompoundBraid: different limbs could be thought of as operating at different scale-addresses.
The KG limb (entity bank = 256 slots) already implements a form of this — it's a stable
high-level sampling over the feature space.

### E. The 2035 Convergence as Motivation
The OSH framework explicitly frames the AI+quantum convergence window as 2032–2040.
We are building this model *inside* that window. Whether or not OSH is literally true,
it reinforces urgency around developing architectures that scale gracefully with quantum backends.
