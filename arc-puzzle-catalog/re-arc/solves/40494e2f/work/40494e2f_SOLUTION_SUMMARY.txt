PATTERN DESCRIPTION:
-------------------
1. Input contains:
   - Large filled rectangles (rect_color)
   - A "stamp" pattern (combination of rect_color and marker_color cells)
   - Background (most common color)

2. Transformation:
   - Place the stamp pattern inside each rectangle
   - If the stamp has "extending arms" (markers that continue 2+ cells), 
     extend those arms to fill the rectangle
   - Erase the original stamp from the output

KEY INSIGHTS:
------------
- Colors are detected by frequency (NOT hardcoded):
  * Background = most common color
  * Rectangle color = 2nd most common
  * Marker color = 3rd most common

- Rectangles are identified as:
  * Large (>= 35 cells for safety after bbox check)
  * Filled (all cells in bounding box are rect_color)
  * Connected components

- Stamp is everything OUTSIDE rectangles (non-background cells)

- Stamp center is found by:
  * Taking bbox center of stamp cells
  * Selecting the cell with most marker neighbors
  * Preferring non-marker cells (to find the "core")

- Arm extension detection:
  * An arm extends if there are markers at positions 1 AND 2 in a direction
  * Arms fill the entire rectangle in that direction from the center

SOLUTION APPROACH:
-----------------
1. Detect colors by frequency
2. Find all large filled rectangles
3. Identify stamp pattern (cells outside rectangles)
4. Find stamp center and build relative pattern
5. For each rectangle:
   - Determine placement position(s)
   - Place stamp core pattern
   - Extend arms if present
6. Erase original stamp
